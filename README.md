# midi

A piano-practice app in the style of Simply Piano: plug a USB-MIDI keyboard into an iPad (or a
laptop or Android device), and the sheet music waits for you to play the right notes.

Built for a Casio LK-S245, but any class-compliant USB-MIDI keyboard should work.

**Status: M0 scaffold.** Wait mode works on one bundled song (an original CC0 arrangement of
_Ode to Joy_). Sound, a song library, falling notes and timed play-along are on the
[roadmap](docs/ARCHITECTURE.md#9-roadmap).

## How it works

- **One web app** (React + TypeScript + Vite) renders sheet music with
  [OpenSheetMusicDisplay](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay) and
  runs a pure, unit-tested wait-mode engine.
- **Laptops and Android** read the keyboard through the browser's Web MIDI API (Chrome or Edge;
  Safari has none).
- **iPad** runs the same web app inside Capacitor. Safari/WebKit has no Web MIDI, so a small local
  plugin ([`native/midi-bridge`](native/midi-bridge)) forwards Core MIDI to JavaScript, built on
  [swift-midi-io](https://github.com/orchetect/swift-midi-io).
- **No keyboard?** Use the on-screen keys or your computer keyboard (`A W S E D F T G Y H U J K`
  = C to C; `Z`/`X` shift the octave).

Design decisions, interfaces and the roadmap are in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Run it in a browser

```sh
npm install
npm run dev
```

Open http://localhost:5173 in Chrome or Edge. Plug the keyboard into the computer and press
**Connect keyboard** (Chrome asks for MIDI permission once). Web MIDI needs a secure context:
`localhost` works, a LAN IP over plain `http` doesn't. For phones and tablets use the GitHub Pages
build (see below).

## Run it on the iPad

Needs a Mac with Xcode 26+ and Node 22+.

```sh
npm ci
npm run ios        # = npm run build && npx cap sync ios && npx cap open ios
```

In Xcode: select the **App** target → _Signing & Capabilities_ → choose your team (a free Apple
ID works, but installs expire after 7 days), pick your iPad as the destination, and Run. Xcode
resolves the Swift packages on the first build and creates `Package.resolved`; commit it.

Connect the LK-S245 with a **USB-C to micro-B data cable** (charge-only cables won't work). Open
**Monitor** in the toolbar to see the device and every MIDI event with its delivery latency.

After changing web code, `npm run build && npx cap sync ios` and run again from Xcode.

## GitHub Pages (laptops and Android)

`.github/workflows/pages.yml` deploys every push to `main`. One-time setup: repo **Settings →
Pages → Source: GitHub Actions**. The app is then at `https://cheapsteak.github.io/midi/`.

## Scripts

| Command                           | What it does                                                                 |
| --------------------------------- | ---------------------------------------------------------------------------- |
| `npm run dev`                     | Dev server                                                                   |
| `npm test`                        | Unit tests (Vitest): MIDI parsing, the wait-mode engine, score extraction    |
| `npm run test:e2e`                | Playwright smoke test in Chrome, driven by a fake MIDI input (`?fakeMidi=1`) |
| `npm run lint` / `npm run format` | Biome                                                                        |
| `npm run typecheck`               | `tsc --noEmit`                                                               |
| `npm run build`                   | Production build into `dist/`                                                |
| `npm run ios`                     | Build, sync and open the iOS project                                         |

## Layout

```
src/midi/       MIDI input: Web MIDI, native bridge, virtual keyboard, parser, hub
src/engine/     wait-mode engine (pure, framework-free)
src/score/      score model, independent of OSMD
src/notation/   ScoreView interface + the OSMD adapter
src/session/    practice session (glue) and Zustand store
src/ui/         React components
native/         local Capacitor plugin (Swift, Core MIDI)
ios/            generated by `npx cap add ios`; don't hand-edit
e2e/            Playwright smoke test
docs/           architecture
```
