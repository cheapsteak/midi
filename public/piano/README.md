# Piano samples

Splendid Grand Piano, MF velocity layer (62 AAC files, ~6.7 MB), from
[smpldsnds/sfzinstruments-splendid-grand-piano](https://github.com/smpldsnds/sfzinstruments-splendid-grand-piano)
([sfzinstruments](https://sfzinstruments.github.io/pianos/splendid_grand_piano)).

Public-domain samples by AKAI: released as public domain in early 2000 by Akai.

File names are smplr's sample names with spaces → `_` and `#` → `s` (mapped in `src/audio/piano.ts`),
so they are safe in every URL scheme, including Capacitor's.
